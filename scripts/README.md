You can use the `setup.sh` for automated symlinking of files.

```sh
vi setup.sh # edit the script variables
./setup.sh # run the script

# Edit the individual scripts compose file paths
vi dcu

# On Alpine Linux, run the commands like this:
bash dcu
```

Usage notes:

1. `dcupda` - script means pull and update all
2. `dcupd` - pull and update in current directory
3. `dcu` - update in current directory
4. `dcp` - pull in current directory
5. `dcua` - script means update all
6. `spotdl` - downloads music from the console
